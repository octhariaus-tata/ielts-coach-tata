# Bukti latihan

Simpan screenshot atau hasil latihan yang memang tersedia di sini. Gunakan subfolder `evidence/<ID-sesi>/` atau nama file yang memuat ID sesi, misalnya `evidence/<ID-sesi>/answers-01.png`. Rujuk lokasi relatif yang sama dari record `sessions/<ID>.json` dan `PROGRESS.md`, agar bukti dapat ditemukan pada laptop lain.

Simpan file asli yang tersedia dan catat sumbernya: screenshot pengguna, keadaan browser saat ini atau hasil ekspor. Jika gambar hanya sebagian, tulis nomor/bagian yang terbaca dan yang belum tersedia. Jika hanya skor total terlihat, simpan skor dengan status itu; jangan mengisi jawaban per soal atau pola kesalahan. Hindari menimpa bukti ketika pengguna mengirim gambar tambahan.

Catat kapan dibaca, materi/versi yang dirujuk, cara verifikasi serta batasnya. Bila bukti hanya tersedia dalam pesan/tool dan tidak dapat diekspor, simpan referensi pesan/tool beserta keterbatasannya; jangan mengklaim file screenshot berhasil disimpan. Periksa hasil penyimpanan dengan membaca ulang file yang tersedia.

Folder ini belum memuat bukti hasil belajar asli. Jangan mengarang screenshot, mengklaim hasil ada, atau mengisi jawaban yang tidak terbaca. Bukti tes sistem harus diberi label dan dipisahkan dari kemajuan Tata. Screenshot latihan ikut sinkron ke repo privat yang diizinkan; keberhasilan penyimpanan lokal dan push dinyatakan terpisah.
